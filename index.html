Traditional CI Only Checks Yesterday's Assumptions

If you introduce a new feature with an unhandled None crash or leave API documentation stale, existing unit tests still pass 100%. Reviewers waste hours on mechanical checks that slips right through CI.

✓

PRism-AI Checks the Full Quality Spectrum Before Review

It pairs real deterministic test execution with three AI specialists to catch implementation bugs, untested behavior gaps, and documentation rot in 30 seconds.

Three Specialists. One Deterministic Gate.

Ordinary code handles Git, test execution, schema validation, and policy. AI models provide deep reasoning over structured evidence.

Stage 1

Context Analyzer

Creates an immutable Git snapshot, extracts AST import graphs, maps callers and callees, and scrubs sensitive credentials.

  • ✓ Resolves Git diff & hunks
  • ✓ AST caller/callee graphing
  • ✓ Excludes secrets & binaries
Stage 2

3 Parallel Specialists

Three independent agents inspect the exact same immutable snapshot simultaneously across three distinct quality domains.

Code Review: Nulls, logic, validation
Testing: Pytest runner & test gaps
Docs: OpenAPI vs api.md sync
Stage 3

Result Aggregator

Deterministic Python validates JSON schemas against schemas/*.json. The AI model never decides whether code is ready.

  • ✓ Strict schema validation
  • ✓ 1 repair round on bad JSON
  • ✓ Deduplication with provenance
Stage 4

Delta Engine

When you fix bugs and re-run with --previous last, it diffs findings to report exactly what is Resolved, Persistent, or New.

  • ✓ Two-pass stateful comparison
  • ✓ Prevents regression blindspots
  • ✓ Clear audit-ready delta table

Install Once. Call from Anywhere.

Just like git or docker, PRism-AI installs as a global terminal command.

1

Install the CLI

Clone the repository and install the prismai command in editable mode:

git clone https://github.com/Hackathon-Repo-Org/PRism-AI-PROD-.git
cd PRism-AI-PROD-
pip install -r requirements.txt
pip install -e .

✓ Installs prismai into your PATH on Windows, macOS, and Linux.

2

Connect Any AI Provider

Works with DeepSeek, OpenAI, Gemini, Claude, or local Ollama:

# Option A: Interactive setup wizard
prismai setup

# Option B: Set environment variable
$env:DEEPSEEK_API_KEY = "sk-..."  # or OPENAI, GEMINI

✓ Your key is saved locally in .prism.env and is never committed.

3

Verify & Use

Run doctor to ensure all systems are green, then point it at any folder:

# Check setup & AI connectivity
prismai doctor

# Run review or chat with codebase
prismai check
prismai chat

✓ Outputs instant findings and writes PRISM-REPORT.md.

What Each Run Leaves Behind

Every PRism-AI run generates an immutable, inspectable run folder. No hidden state, no mystery verdicts.

runs/<runId>/
Isolated run directory with timestamp & candidate commit hash
report.md
Actionable human-readable report with exact file, line, and remediation
report.json
Machine-readable JSON schema validated against schemas/report.schema.json
delta.md
Stateful comparison with previous run (Resolved vs. Persistent)
context.json
Shared immutable snapshot data, AST import graphs, and exclusions
logs/pytest.log
Raw execution logs and JUnit XML from the project's actual test run

What "READY FOR HUMAN REVIEW" Means

Review readiness is a scoped, verifiable state — never blind approval to merge or deploy without human judgment.

  • All 3 Specialist Checks Completed: Code Review, Testing, and Documentation agents all executed within timeout.
  • Deterministic Tests Passed: The project's build and test commands exited with code 0.
  • Zero Policy Blockers: No unhandled exceptions, SQL injection, null dereferences, or contract drifts remain open.
  • Full Provenance Preserved: Every finding is anchored to an exact file path, line number, and verifiable evidence.
